# Faryal Zahid — Portfolio

A simple three-page portfolio built with HTML and CSS.

## Files

- `index.html` — designer / coder hero
- `work.html` — selected projects
- `about.html` — about + experience
- `Styles.css` — shared stylesheet for all pages
- `images/faryal-hero.png` — transparent hero artwork
- `images/fz-logo.png` — FZ logo

Open `index.html` in VS Code with Live Server to preview it.

The home hero intentionally stays horizontal on smaller screens: the text, portrait and coder text resize rather than stacking vertically.
